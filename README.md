# APUNAB - Sistema de Gestión de Puntos

Sistema de Gestión de Puntos APUNAB para estudiantes de la Universidad Autónoma de Bucaramanga (UNAB).

## Descripción

Aplicación gráfica en Java que permite a los estudiantes gestionar, consultar y proyectar sus puntos APUNAB. La aplicación facilita el cumplimiento del requisito de 100.000 puntos para graduarse mediante el seguimiento centralizado de transacciones, cálculo de promedios y proyecciones de avance.

## 10 Funcionalidades

- [ ] Implementación de tema claro y oscuro manual
- [ ] Adaptación automática del tema según el sistema operativo
- [ ] Cambio dinámico del tema según la hora del día
- [ ] Búsqueda de lugares por nombre
- [ ] Filtros de lugares por categoría
- [ ] Gestión de lugares favoritos
- [ ] Historial de transacciones de APUNAB
- [ ] Edición de perfil de usuario
- [ ] Notificaciones internas
- [ ] Exportación de reportes en CSV
